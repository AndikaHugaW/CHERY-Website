# 🚗 CHERY Salatiga — Website Dealer Resmi

Website Company Profile & Katalog Digital Interaktif untuk **Dealer Resmi Chery Salatiga**, Jawa Tengah.  
Menampilkan lini produk kendaraan Chery terbaru (BEV, CSH / Super Hybrid, dan ICE) dengan pengalaman visual modern, responsif, dan terintegrasi langsung dengan layanan dealer.

🌐 **Website:** [https://cherysalatiga.id](https://cherysalatiga.id)

---

## ✨ Fitur-Fitur Website

### 1. 🚘 Katalog & Jajaran Unit Kendaraan
- **Katalog Lengkap Seluruh Lini Chery**:
  - **BEV (Battery Electric Vehicle)**: CHERY Q, CHERY J6T, CHERY E5
  - **CSH (Chery Super Hybrid / REEV)**: CHERY J6T CSH, TIGGO 9 CSH, TIGGO 8 CSH, TIGGO CROSS CSH
  - **ICE (Internal Combustion Engine)**: TIGGO 8 PRO MAX, TIGGO 8, TIGGO CROSS SPORT, TIGGO CROSS
- **Urutan Unit Presisi**: Penempatan prioritas unit unggulan (misal: CHERY J6T CSH langsung di bawah CHERY Q).
- **Pencarian & Filter Multi-Kategori**:
  - Filter cepat berdasarkan kategori powertrain: **All**, **BEV**, **CSH**, dan **ICE**.
  - Filter berdasarkan model mobil dan jenis transmisi (Automatic / Manual).
  - Pencarian teks instan (nama model, tagline, spesifikasi mesin).
- **Sorting Dinamis**: Pengurutan berdasarkan Terpopuler/Terbaru, Harga Terendah, Harga Tertinggi, dan Nama A–Z.
- **Kartu Kendaraan Informatif**:
  - Foto resolusi tinggi dengan badge ketersediaan (*Tersedia*, *Ready*, dll.).
  - Indikator badge powertrain (BEV / CSH / ICE).
  - Quick specs ringkas: Tipe Mesin/Motor, Tenaga (PS/HP/kW), Kapasitas Penumpang, dan Transmisi.
  - Informasi harga OTR mulai dari dan tombol aksi cepat.
